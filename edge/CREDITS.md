# Dataset Credits

The following Roboflow Universe datasets were inspected as potential Track 2 plate-detection sources. The selected v2 export is downloaded locally under the Git-ignored `edge/data/` directory but has not been used for training yet.

- [Indian License Plate Detection](https://universe.roboflow.com/license-plate-detection-khhkb/indian-license-plate-detection-6tmbr) - 833-image object-detection dataset, CC BY 4.0.
- [Indian-License-Plate-Merged](https://universe.roboflow.com/abduls-workspace-qwhgu/indian-license-plate-merged) - public Indian plate object-detection dataset, CC BY 4.0. Roboflow dataset version 2 was selected and downloaded for pretraining because it contains 9,562 images.

If either dataset is later used in training or a published model/output, retain attribution as required by CC BY 4.0.
